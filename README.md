# WiFi Vendo

Independent modular coin-operated Wi-Fi vending system. Initial scaffold and implementation are developed against the JuanFi functional requirements.

## Hardware targets
- ESP8266 Wi-Fi
- ESP32 Wi-Fi
- ESP32 W5500 Ethernet

## Operating modes
- MikroTik RouterOS Hotspot integration
- Standalone captive portal / local authentication mode

## Display
LCD support is intentionally excluded from the selected hardware configuration.

See docs/FEATURE-MATRIX.md and docs/DEVELOPMENT.md.
